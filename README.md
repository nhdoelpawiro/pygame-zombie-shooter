# Dead Woods

Dead Woods is a top down zombie survival game made with Python and Pygame. You fight off 10 waves of zombies without trying to get killed.

## Requirements

- Python
- Pygame

Install Pygame using pip:

```
pip install pygame
```

## How to run

1. Download or clone the repository
2. Install Python and Pygame
3. Run the game with:

```
python main.py
```

## How to Play

   WASD to move, left mouse button to shoot. Each round spawns more zombies, so keep moving and watch your health. Good luck!
